# Getting started

Safernotes can run as an offline vault or synchronize with your own server.

- Install the Android app and choose **Use offline only** for local use.
- Follow [Self-hosting](SELF_HOSTING.md) to deploy the web app and sync server.
- Follow [Development](DEVELOPMENT.md) to build or contribute to the project.

Run commands from the repository root unless a guide explicitly changes directory.
All paths in the documentation are relative to that root.
